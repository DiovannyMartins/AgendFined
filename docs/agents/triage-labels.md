# Triage labels

Mapeamento entre os papéis usados pelas skills do Matt Pocock e as labels do GitHub deste projeto:

| Papel | Label | Uso |
| --- | --- | --- |
| needs-triage | needs-triage | Issue aguardando avaliação |
| needs-info | needs-info | Falta informação do solicitante |
| ready-for-agent | ready-for-agent | Issue especificada para execução por agente |
| ready-for-human | ready-for-human | Requer decisão ou implementação humana |
| wontfix | wontfix | Não será implementada |

Quando uma skill mencionar um papel de triagem, use a label correspondente acima.
